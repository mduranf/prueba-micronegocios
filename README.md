# prueba-micronegocios

Este repositorio desarrolla la prueba de programación para la SDDE. 

## Insumos
Para esta prueba, se cuentan con tres archivos insumo provistos por la SDDE en formato .xlsx

## Objetivo
En el desarrollo de la prueba, se llevan a cabo tareas de estandarización de bases de datos, análisis de estadísticas descriptivas y descipción de distintos flujos de trabajo

## Tareas
A continuación, las tareas de este repositorio en el orden en el que deben ejecutarse
1. La tarea [importar](https://github.com/mduranf/prueba-micronegocios/tree/main/importar) importa los archivos de datos `desembolsos.xlsx` y `unidades.xlsx`, elimina mayúsculas, espacios y caracteres especiales de los nombres de sus variables para facilidad de las siguientes tareas, y los exporta modificados. En este caso se exportan en .xlsx por facilidad para quieres revisen esta prueba.
2. La tarea [analisis](https://github.com/mduranf/prueba-micronegocios/tree/main/analisis) toma como insumo los archivos en el [output de importar](https://github.com/mduranf/prueba-micronegocios/tree/main/importar/output) para ejecutar los puntos 1 al 4 de la prueba. En el [output de analisis](https://github.com/mduranf/prueba-micronegocios/tree/main/analisis/output), se encuentra la base de datos resultante del punto 1, nuevamente, en formato xlsx.
